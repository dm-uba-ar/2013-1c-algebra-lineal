# **Régimen de Aprobación de la Materia**

- Para firmar los trabajos prácticos se deben aprobar dos exámenes parciales. Habrá dos fechas de recuperación, una para cada examen parcial.

- Para poder ser incluido en las Actas, en caso de aprobar los trabajos prácticos, es necesario haberse inscripto en la materia (a través del [Sistema de Inscripciones de la Facultad](http://inscripciones.exactas.uba.ar/exactas/)) y haber completado la encuesta de evaluación docente.
